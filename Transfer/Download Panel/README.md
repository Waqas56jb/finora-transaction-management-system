# Transfer/Download Panel

Full development of this panel is scheduled for Milestones 2 and 3.

Milestone 1 does not implement transfers, downloads, settlement files, or any live movement of funds. The Admin, Loading, and Transaction History applications link here only as a planned item labelled “Coming in Milestone 2–3”.

When this panel is built, it should remain a separate React application and should call an authorized backend in `server/`. It must not present a simulated transfer as a completed payment.
